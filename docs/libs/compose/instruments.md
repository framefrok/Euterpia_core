# Инструменты и ноды «из коробки»

В реестре ядра **28 типов**: 10 DSP-нод, **17 инструментов** и нотный
секвенсор `notes`. Полный список нод с параметрами (имя — диапазон —
значение по умолчанию). Параметры задаются по имени или по числовому id:

```nim
inst.setParam("level", -6.0f32)   # по имени (стабильно)
```

Уровень `level` — в дБ (`-80` = тишина). `pan` — стерео, `-1..+1`.

Список проверяется тестом `tests/unit/test_docs_instruments.nim`: новый тип
или новый параметр, не попавшие в этот файл, валят сборку (#309). Проверить
живой список: `euterpia node types --json`.

## Инструменты

Все инструменты — источники: аудиовхода нет, ноты приходят событиями. У каждого
есть `pan` и `level`.

### `euterpia.guitar` — гитара (Карплус-Стронг)
Струна Карплуса-Стронга в тракте электрогитары: тело корпуса (мягкая полка
ниже 200 Гц — плотная нижняя середина, а не пустота), двухполюсный демпфер
струны (хвост затухает ровно, без «цифрового» квака) и огибающая строя —
сильный щипок коротко «въезжает» вверх и садится за ~35 мс, как у живой
струны. После струны — кабинет и насыщение усилителя; панораму ставит движок
(гитара моно внутри голоса).
| параметр | диапазон | по умолчанию | смысл |
|---|---|---|---|
| `pick` | 0.02..0.95 | 0.5 | позиция щипка по струне |
| `damping` | 0..1 | 0.35 | поглощение в струне |
| `tone` | 0..1 | 0.6 | яркость после фильтра |
| `drive` | 0..1 | 0.2 | насыщение |
| `mute` | 0..1 | 0 | palm mute |
| `release` | 0.01..2 | 0.4 | гашение после note-off, с |
| `pan` | -1..1 | 0 | панорама |
| `level` | -80..6 | -6 | уровень, дБ |

### `euterpia.flute` — флейта (почти синус + дыхание)
| параметр | диапазон | по умолчанию | смысл |
|---|---|---|---|
| `tone` | 0..1 | 0.55 | яркость (верхние гармоники) |
| `breath` | 0..1 | 0.35 | дыхание (полосовой шум — воздух, не шипение) |
| `vibrato` | 0..60 | 8 | глубина вибрато, центы (включается плавно после атаки) |
| `pan` | -1..1 | 0 | панорама |

Флейта **монофонична**: новая нота быстро гасит прежний голос, поэтому
легато не превращается в двух звучащих флейт (это и давало «фальшь»).

### `euterpia.strings` — смычковые (струнный ансамбль)
Пила через корпусный ФНЧ, задержанное вибрато, микрорасстройка голосов.
Один инструмент покрывает скрипку/альт/виолончель — тембром управляют
`tone` и регистр ноты (низкие ноты звучат глубже, высокие — ярче).
| параметр | диапазон | по умолчанию | смысл |
|---|---|---|---|
| `tone` | 0..1 | 0.5 | яркость (срез ФНЧ) |
| `vibrato` | 0..60 | 10 | глубина вибрато, центы |
| `ensemble` | 0..30 | 7 | разброс расстройки голосов, центы (глубина ансамбля) |
| `pan` | -1..1 | 0 | панорама |
| `level` | -80..6 | -8 | уровень, дБ |

### `euterpia.bell` — колокол (трубчатый/церковный)
Сумма ингармонических частичных с индивидуальным затуханием: высокие гаснут
быстрее, поэтому звон со временем темнеет. Нотой не глушится — звенит до
естественного затухания.
| параметр | диапазон | по умолчанию | смысл |
|---|---|---|---|
| `tune` | 0.25..4 | 1.0 | множитель строя |
| `decay` | 0.1..30 | 4.0 | длина звона, секунды |
| `tone` | 0..1 | 0.5 | яркость (наклон частичных) |
| `pan` | -1..1 | 0 | панорама |
| `level` | -80..6 | -8 | уровень, дБ |

### `euterpia.harp`, `euterpia.harpsichord` и `euterpia.ukulele` — щипковые (Карплус-Стронг)
Один движок, три характера: **арфа** — длинный тёплый звон и мягкий щипок,
**клавесин** — короткий яркий «перьевой», с высоким корпусом-декой,
**укулеле** — нейлоновая струна (`nylon = 1`): мягче возбуждение и быстрее
спад верха, поэтому щипок глухой и «деревянный», а не стеклянный.
Параметры у всех одинаковые, различаются умолчания.

| параметр | диапазон | по умолчанию (арфа / клавесин / укулеле) | смысл |
|---|---|---|---|
| `tone` | 0..1 | 0.55 / 0.85 / 0.42 | яркость струны |
| `damping` | 0..1 | 0.78 / 0.42 / 0.55 | длина звона (0 — короткий щипок, 1 — длинный) |
| `pluck` | 0..1 | 0.35 / 0.78 / 0.55 | резкость щипка |
| `body` | 0..1 | 0.45 / 0.28 / 0.32 | глубина резонатора корпуса |
| `nylon` | 0..1 | 0 / 0 / 1 | доля нейлоновой струны: 0 — сталь, 1 — нейлон |
| `pan` | -1..1 | 0 | панорама |
| `level` | -80..6 | -8 / -9 / -9 | уровень, дБ |

`nylon` — не переключатель, а доля: 0.5 даёт промежуточную струну. При
`nylon = 0` путь обработки прежний (арфа и клавесин звучат как раньше).

### `euterpia.recorder` — свирель/блокфлейта (деревянный духовой)
Как флейта, но спектр «деревянный»: заметна 2-я гармоника и мягкая 4-я.
Монофоничный, как и флейта (новая нота гасит прежний голос).
| параметр | диапазон | по умолчанию | смысл |
|---|---|---|---|
| `tone` | 0..1 | 0.6 | яркость |
| `breath` | 0..1 | 0.30 | дыхание (шум) |
| `vibrato` | 0..60 | 5 | глубина вибрато, центы |
| `pan` | -1..1 | 0 | панорама |
| `level` | -80..6 | -6 | уровень, дБ |

### `euterpia.brass` — медь (труба/валторна)
Пила (band-limited) через формантный резонатор меди, мягкий ФНЧ-раструб.
Вибрато включается после атаки, в атаку подмешивается шум — нота «въезжает».
| параметр | диапазон | по умолчанию | смысл |
|---|---|---|---|
| `tone` | 0..1 | 0.55 | яркость/открытость раструба |
| `rasp` | 0..1 | 0.35 | жёсткость атаки (шумовой призвук) |
| `vibrato` | 0..60 | 6 | глубина вибрато, центы |
| `pan` | -1..1 | 0 | панорама |
| `level` | -80..6 | -8 | уровень, дБ |

### `euterpia.timpani` — литавры (настраиваемый барабан)
Удар **со строем**: моды 1 : 1.504 : 2 : 2.61 затухают с разной скоростью,
поэтому звон со временем темнеет. Нотой не глушится — звенит до конца.
| параметр | диапазон | по умолчанию | смысл |
|---|---|---|---|
| `tune` | 0.25..4 | 1.0 | строй, множитель |
| `decay` | 0.1..8 | 1.0 | длина звона, множитель |
| `tone` | 0..1 | 0.5 | яркость и шум атаки |
| `pan` | -1..1 | 0 | панорама |
| `level` | -80..6 | -6 | уровень, дБ |

### `euterpia.choir` — хор (формантные гласные)
Источник-«голосовая щель» плюс три форманты гласной. `vowel` переводит
«а» → «о» → «и»; коэффициенты пересчитываются каждый блок, поэтому гласную
можно вести автоматизацией.
| параметр | диапазон | по умолчанию | смысл |
|---|---|---|---|
| `vowel` | 0..1 | 0 («а») | 0.5 — «о», 1 — «и» |
| `tone` | 0..1 | 0.5 | яркость источника (верхние форманты) |
| `vibrato` | 0..60 | 9 | глубина вибрато, центы |
| `pan` | -1..1 | 0 | панорама |
| `level` | -80..6 | -8 | уровень, дБ |

### `euterpia.accordion` и `euterpia.harmonica` — свободноязычковые (язычок в камере)
Один движок, два характера — как у щипковых. Звук делает не струна и не
столб воздуха, а **язычок в камере**, поэтому у обоих есть разлив
(несколько расстроенных язычков на ноту), шум воздуха (мех или дыхание) и
посадка строя после атаки. Различаются ровно два числа:

* **баян/аккордеон** — разлив 12 центов (язычки «врозь», слышны биения) и
  низкая камера ≈1.4 кГц;
* **губная гармошка** — язычок на ноту один (разлив 0), быстрая атака и
  высокая «носовая» камера ≈2.6 кГц.

| параметр | диапазон | по умолчанию (баян / гармошка) | смысл |
|---|---|---|---|
| `tone` | 0..1 | 0.5 / 0.72 | яркость язычка (доля меандра в источнике, «гнусавость») |
| `detune` | 0..40 | 12 / 0 | разлив между язычками, центы (0 — сухой строй) |
| `noise` | 0..1 | 0.28 / 0.2 | воздух: шум меха или дыхания |
| `attack` | 0.002..0.5 | 0.05 / 0.018 | время речи язычка, с |
| `pan` | -1..1 | 0 | панорама |
| `level` | -80..6 | -8 / -9 | уровень, дБ |

Громкая нота звучит «гнусавее» мягкой: нелинейность язычка растёт от
давления (velocity), а не только от уровня выхода.

## Справочник нот (MIDI)

- **Имена в нотации:** `c4` = 60 (до первой октавы), `a4` = 69 = 440 Гц;
  `c#4`/`db4` — диез/бемоль, октава — цифрой.
- **Ударные (GM):** 36 бочка, 38 малый, 39 хлопок, 41/43/45/48 томы,
  42 закрытый хэт, 44 педальный хэт, 46 открытый хэт, 49 crash, 51 ride.
- **Диапазоны инструментов:** орган/пиано/гитара — примерно 36..96;
  флейта удобна в 60..84; шантир волынки — 55..79; смычковые — 40..84
  (низкие ноты глубже — виолончель, высокие ярче — скрипка); колокол — 55..84;
  арфа — 24..96, клавесин — 36..84; свирель — 60..88; медь — 45..79;
  литавры — 36..60 (ударный инструмент со строем); хор — 48..79;
  укулеле — 48..84 (нейлоновая струна глуше стали); баян — 41..84,
  гармошка — 48..84.
