# Инструменты и ноды «из коробки»

Полный список нод ядра с параметрами (имя — диапазон — значение по умолчанию).
Параметры задаются по имени или по числовому id:

```nim
inst.setParam("level", -6.0f32)   # по имени (стабильно)
```

Уровень `level` — в дБ (`-80` = тишина). `pan` — стерео, `-1..+1`.

## Инструменты

Все инструменты — источники: аудиовхода нет, ноты приходят событиями. У каждого
есть `pan` и `level`.

### `euterpia.organ` — орган (аддитивный, 8 частий)
| параметр | диапазон | по умолчанию | смысл |
|---|---|---|---|
| `bars` | 0..1 | 0.35 | положение регистровой ручки (0 — флейты, 1 — полный микст) |
| `tone` | 0..1 | 0.6 | яркость частий |
| `click` | 0..1 | 0.35 | щелчок атаки клавиши |
| `vibrato` | 0..60 | 6 | глубина вибрато, центы |
| `pan` | -1..1 | 0 | панорама |
| `level` | -80..6 | -6 | уровень, дБ |

## Секвенсор и сумматор

### `euterpia.notes` — нотный секвенсор
Ноты приходят дорожкой проекта (`Arrangement`/`Builder`), а не параметрами.
| параметр | диапазон | по умолчанию | смысл |
|---|---|---|---|
| `transpose` | -36..36 | 0 | сдвиг, полутоны |
| `velocity` | 0..2 | 1.0 | множитель velocity |
| `channel` | 0..16 | 16 | MIDI-канал (16 — «любой») |
| `loop` | 0..1 | 0 | зациклить рисунок до длины клипа |
| `length` | 0..65536 | 0 | длина, тики (0 — из клипа) |
| `swing` | 0..0.75 | 0 | свинг восьмых |

### `euterpia.mix` — сумматор
8 аудиовходов → 1 выход, с DC-блокером.
| параметр | диапазон | по умолчанию | смысл |
|---|---|---|---|
| `level` | -80..12 | 0 | уровень суммы, дБ |

## Генераторы, фильтры, эффекты (для графа через Builder)

Их удобно собирать в цепочки: `osc → biquad → delay → mix`.

### `euterpia.osc` — осциллятор
| параметр | диапазон | по умолчанию |
|---|---|---|
| `waveform` | 0..3 | 0 (0 sine, 1 saw, 2 square, 3 triangle) |
| `freq` | 0.01..20000 | 440 |
| `level` | -80..6 | -6 |
| `detune` | -50..50 | 0 (расстройка L/R, центы) |
| `width` | 0.05..0.95 | 0.5 (ширина импульса) |

### `euterpia.noise` — шум
| параметр | диапазон | по умолчанию |
|---|---|---|
| `color` | 0..2 | 0 (0 white, 1 pink, 2 brown) |
| `level` | -80..6 | -20 |

### `euterpia.biquad` — биквадратный фильтр
| параметр | диапазон | по умолчанию |
|---|---|---|
| `type` | 0..6 | 0 (LP/HP/BP/NOTCH/PEAK/LOW_SHELF/HIGH_SHELF) |
| `cutoff` | 10..20000 | 1000 |
| `q` | 0.05..20 | 0.707 |
| `gain` | -24..24 | 0 (для shelf/peak, дБ) |

### `euterpia.svf` — фильтр с переменным состоянием
| параметр | диапазон | по умолчанию |
|---|---|---|
| `type` | 0..3 | 0 (LP/HP/BP/NOTCH) |
| `cutoff` | 10..20000 | 1000 |
| `reso` | 0.05..4 | 1.0 |

### `euterpia.delay` — дилей
| параметр | диапазон | по умолчанию |
|---|---|---|
| `time_l` | 0.001..4 | 0.25 (с) |

### `euterpia.compressor` — компрессор
| параметр | диапазон | по умолчанию |
|---|---|---|
| `threshold` | -60..0 | -18 (дБ) |

## Справочник нот (MIDI)

- **Имена в нотации:** `c4` = 60 (до первой октавы), `a4` = 69 = 440 Гц;
  `c#4`/`db4` — диез/бемоль, октава — цифрой.
- **Ударные (GM):** 36 бочка, 38 малый, 39 хлопок, 41/43/45/48 томы,
  42 закрытый хэт, 44 педальный хэт, 46 открытый хэт, 49 crash, 51 ride.
- **Диапазоны инструментов:** орган/пиано/гитара — примерно 36..96;
  флейта удобна в 60..84; шантир волынки — 55..79.

## Быстрый указатель нод

| id | категория |
|---|---|
| `euterpia.organ`, `euterpia.piano`, `euterpia.guitar`, `euterpia.drums`, `euterpia.flute`, `euterpia.bagpipe` | инструменты |
| `euterpia.notes` | секвенсор (ноты дорожки → события) |
| `euterpia.osc`, `euterpia.noise` | генераторы |
| `euterpia.biquad`, `euterpia.svf` | фильтры |
| `euterpia.gain`, `euterpia.pan`, `euterpia.mix` | микширование |
| `euterpia.compressor`, `euterpia.delay` | динамика и эффекты |
| `euterpia.input` | входной тракт |

Полный актуальный каталог всегда доступен командой:

```bash
build/euterpia node types          # человекочитаемо
build/euterpia --json node types   # с параметрами и диапазонами
```
