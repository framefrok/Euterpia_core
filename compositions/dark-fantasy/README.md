# Cathedral of Ash — medieval dark fantasy

Симфоническая пьеса-витрина (#295): показывает и звук инструментов ядра, и
**«композицию как код»** через библиотеку `libs/compose` (#285). Ни Editor, ни
внешних скриптов — только Nim и команды ядра (MANIFEST §19).

## Пьеса

**≈4:02** (76 тактов 4/4 при 76 BPM), ре минор с модальными красками
(Aeolian, фригийская секунда E♭ в «Катаклизме»), средневековая звучность:
органум-параллелизм (открытые квинты), плагальные кадансы, церковный орган
как соборный хор, лютня как голос.

| часть | такты | что происходит |
|---|---|---|
| I. Пролог | 1–12 | органный бурдон, хоральный напев лютни |
| II. Марш | 13–32 | боевые барабаны (томы), маршевая тема, орган-хор с педалью |
| III. Плач | 33–48 | высокий печальный напев, редкие удары-«сердце» |
| IV. Катаклизм | 49–64 | хорал звучит октавой выше (вершина), татаны, фригийская E♭ |
| V. Эпилог | 65–76 | распад на бурдон, удар-точка, каданс в ре |

Партии: **organ** (хор + бурдон), **guitar** (лютня), **piano** (арфа),
**drums** (боевые барабаны).

## Сборка

```bash
./build.sh                 # библиотека libs/compose + рендер/анализ через CLI
./build.sh /path/to/euterpia
./build_via_cli.sh         # тот же проект, собранный ТОЛЬКО через CLI (§19)
```

`build.sh` запускает `generate.nim`: форма, мотивы и развитие описаны на Nim
через `libs/compose`, и на выход идут

- `*.notes` — партитуры в текстовой нотации ядра (человеку и CLI),
- `ensemble.eut` — готовый проект (ноды, связи, параметры из описателей,
  дорожки с нотами), собранный средствами Core (`core/project`).

Дальше ядро считает и проверяет: `graph check` → `render` → `analyze`.

`build_via_cli.sh` собирает тот же состав **только командами CLI** (`init`,
`node add`, `connect`, `param set`, `notation import`) — это критерий §19;
его результат совпадает с библиотечным.

## Файлы

| файл | что |
|---|---|
| `generate.nim` | форма, мотивы и развитие на Nim → `.notes` + `.eut` |
| `*.notes` | партитуры в текстовой нотации ядра |
| `build.sh` | сборка библиотекой `libs/compose` + CLI-рендер |
| `build_via_cli.sh` | альтернатива: сборка только через CLI (§19) |
| `ensemble.*` / `ensemble_cli.*` | артефакты сборки (в git не хранятся) |

Изменение музыки: правьте `generate.nim`, затем `./build.sh`.
