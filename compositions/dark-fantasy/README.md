# Cathedral of Ash — medieval dark fantasy

Симфоническая пьеса-витрина (#295): показывает и звук инструментов ядра, и
сборку **только через CLI** (MANIFEST §19). Собирается и рендерится без Editor.

## Пьеса

**≈4:02** (76 тактов 4/4 при 76 BPM), ре минор с модальными красками
(Aeolian, фригийская секунда E♭ в «Катаклизме»), средневековая звучность:
органум-параллелизм (открытые квинты), плагальные кадансы, церковный орган
как соборный хор, лютня как голос.

Форма с развитием:

| часть | такты | что происходит |
|---|---|---|
| I. Пролог | 1–12 | органный бурдон, хоральный напев лютни |
| II. Марш | 13–32 | боевые барабаны (томы), маршевая тема, орган-хор с педалью |
| III. Плач | 33–48 | высокий печальный напев, редкие удары-«сердце» |
| IV. Катаклизм | 49–64 | хорал звучит октавой выше (регистровая вершина), татаны, фригийская E♭ |
| V. Эпилог | 65–76 | распад на бурдон, удар-точка, каданс в ре |

Партии: **organ** (соборный хор + бурдон), **guitar** (лютня, напевы),
**piano** (арфа/колокольчики), **drums** (боевые барабаны, томы, тарелки).

## Сборка

```bash
./build.sh                 # использует ../../build/euterpia
./build.sh /path/to/euterpia
```

Шаги (все — команды CLI): `init` → `node add` (9 нод) → `connect` (8 связей) →
`param set` (баланс) → `notation import` (4 партии) → `graph check` → `render`
→ `analyze`. Результат: `ensemble.wav` (48 кГц, PCM 16, стерео).

Порядок импорта партий важен: загрузчик сцены сопоставляет дорожки с нотными
нодами по возрастанию id, поэтому партии идут в порядке создания нотных нод
(лютня, пиано, орган, ударные).

## Файлы

| файл | что |
|---|---|
| `generate.py` | форма, мотивы и развитие → `.notes` |
| `*.notes` | партитуры в текстовой нотации ядра |
| `build.sh` | сборка проекта и рендер только через CLI |
| `ensemble.eut` / `ensemble.wav` | артефакты сборки (в git не хранятся) |

Изменение музыки: правьте `generate.py`, затем `./build.sh`.
