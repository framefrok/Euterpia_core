# Cathedral of Ash — medieval dark fantasy

Симфоническая пьеса-витрина (#295, продолжение #274/#300): показывает и звук
инструментов, и **«композицию как код»** через `libs/compose`. Ни Editor, ни
внешних скриптов — только Nim и команды ядра.

## Пьеса

**≈3:33** (88 тактов 4/4 при 100 BPM), ре минор с модальными красками
(Aeolian, фригийская E♭ в «Charge»), средневековая звучность: органум-квинты,
церковный орган как хор, лютня, **флейта** и **волынка** (бурдон + шантир).

| часть | такты | что происходит |
|---|---|---|
| I. Dawn | 1–12 | органный бурдон, зов флейты, тишина ударных |
| II. March | 13–32 | марш лютни, боевые томы, орган с педалью |
| III. Charge | 33–52 | **волынка**: бурдон + шантир; ударные разгоняются (четверти → восьмые → шестнадцатые) |
| IV. Lament | 53–68 | флейта ведёт плач, пиано и «сердце» барабанов |
| V. Finale | 69–88 | полный ансамбль, хорал, каденция |

**Про «ускорение»:** реальный rubato (карта темпа) — отдельная задача ядра
(#302); пока разгон выражен **плотностью** (восьмые → шестнадцатые) и динамикой,
что даёт ощущение accelerando без разрыва позиции в тиках.

Партии: **organ**, **piano**, **guitar** (лютня), **flute**, **bagpipe**
(бурдон + шантир), **drums**.

## Сборка

```bash
./build.sh                 # генерация + рендер (libs/compose) + инспекция
nim r generate.nim         # то же вручную: пишет .notes, .eut и .wav
./build_via_cli.sh         # альтернатива: сборка только через CLI (§19)
```

`generate.nim` описывает форму, мотивы и партии на Nim и **сам** пишет партитуры
(`*.notes`), проект (`ensemble.eut`) и звук (`ensemble.wav`) — рендер идёт через
`libs/compose/engine` (те же `loadScene` + `renderToWav`, что у CLI).
