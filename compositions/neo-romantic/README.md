# Neo-Romantic Ensemble

Оркестровая пьеса для четырёх инструментов ядра: эталон для инспектора
аудио (#275) и пример **«композиции как код»** через библиотеку `libs/compose`
(#285). Собирается без Editor — только Nim и команды ядра (MANIFEST §19).

## Пьеса

**≈2:48** (64 такта 4/4 при 92 BPM), ля минор с модальными отклонениями.

| часть | такты | что происходит |
|---|---|---|
| интро | 1–8 | орган-пэд, затем арпеджио пиано |
| A | 9–24 | тема у гитары, грув ударных, пиано |
| B | 25–40 | подъём (Dm–B♭–F–C), гитара отвечает длинными нотами |
| A′ | 41–56 | тема на октаву выше (кульминация), доминанта E |
| кода | 57–64 | разрешение F–G–Am, затухание |

Партии: **guitar** (мелодия), **piano** (арпеджио), **organ** (пэд),
**drums** (грув).

## Сборка

```bash
./build.sh                 # библиотека libs/compose + рендер/анализ через CLI
./build.sh /path/to/euterpia
./build_via_cli.sh         # тот же проект, собранный ТОЛЬКО через CLI (§19)
```

`build.sh` запускает `generate.nim`: форма и мотивы описаны на Nim через
`libs/compose`, и на выход идут `*.notes` (нотация ядра) и `ensemble.eut`
(готовый проект — ноды, связи, параметры из описателей, дорожки с нотами).

`build_via_cli.sh` собирает тот же состав **только командами CLI** (`init`,
`node add`, `connect`, `param set`, `notation import`) — критерий §19. Оба
пути дают идентичный рендер (peak −6.13 dBFS, RMS −23.78 dBFS, 0 error/0 warn).

## Файлы

| файл | что |
|---|---|
| `generate.nim` | форма и мотивы на Nim → `.notes` + `.eut` + `.wav` + `.mid` |
| `*.notes` | партитуры в текстовой нотации ядра |
| `midi/` | по MIDI-файлу на инструмент (артефакт сборки) |
| `build.sh` | сборка библиотекой `libs/compose` + CLI-рендер |
| `build_via_cli.sh` | альтернатива: сборка только через CLI (§19) |
| `ensemble.*` / `ensemble_cli.*` | артефакты сборки (в git не хранятся) |

Изменение музыки: правьте `generate.nim`, затем `./build.sh`.
