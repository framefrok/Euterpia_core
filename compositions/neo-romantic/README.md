# Neo-Romantic Ensemble

Оркестровая пьеса для четырёх инструментов ядра, которая собирается **только
CLI** (MANIFEST §19) и служит одновременно:

- проверкой §19 («любой проект — без Editor»);
- демонстрацией инструментов оркестра (#274);
- эталоном для инспектора аудио (#275, #290).

## Пьеса

- **форма:** интро (8 тактов) — A (16) — B (16) — A′ (16) — кода (8) = 64 такта;
- **темп/размер:** 92 BPM, 4/4 → **≈2:48**;
- **тональность:** ля минор с модальными отклонениями (оборот Am–F–C–G и
  подъём Dm–B♭–F–C в разделе B);
- **партии:** орган (пэд), пиано (арпеджио), гитара (мелодия), ударные (грув);
- **выразительность:** velocity меняется по разделам, ударные входят в A,
  в B переходят на ride, в коде — crash и разрежение.

Ноты не написаны руками, а **сгенерированы детерминированно**: `generate.py`
держит форму и гармонию, а на выход даёт четыре файла нотации ядра.

## Сборка

```bash
./build.sh                 # использует ../../build/euterpia
./build.sh /path/to/euterpia
```

Шаги (все — команды CLI): `init` → `node add` (9 нод) → `connect` (8 связей) →
`param set` (баланс) → `notation import` (4 партии) → `graph check` → `render`
→ `analyze`. Результат: `ensemble.wav` (48 кГц, PCM 16, стерео).

Порядок импорта партий важен: загрузчик сцены сопоставляет дорожки с нотными
нодами по возрастанию id, поэтому партии импортируются в том же порядке, в
каком создавались нотные ноды (гитара, пиано, орган, ударные).

## Файлы

| файл | что |
|---|---|
| `generate.py` | форма, гармония и партии → `.notes` |
| `*.notes` | партитуры в текстовой нотации ядра |
| `build.sh` | сборка проекта и рендер только через CLI |
| `ensemble.eut` | собранный проект (результат `build.sh`) |
| `ensemble.wav` | рендер (артефакт, в git не хранится) |

Изменение музыки: правьте `generate.py`, затем `./build.sh`.
