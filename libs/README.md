# libs/ — библиотеки EUTERPIA

Здесь живут **наши библиотеки** — переиспользуемый код верхнего слоя, который
строится поверх Core и Nodes и которым пользуются CLI, Editor и прикладные
программы (например, генераторы композиций). Ни Core, ни Nodes о `libs/` не
знают: зависимости идут строго в одну сторону (`Core ← Nodes ← libs ← CLI`).

## Что здесь есть

| библиотека | назначение |
|---|---|
| `compose/` | «композиция как код» (#285): модель партитуры и сборка `.eproj`-проектов из Nim |
| `midi_export` | проект → Standard MIDI File: один файл или по файлу на инструмент |

## `midi_export`

Единственное место, где видны сразу и проект (`core/project`), и кодек
(`commons/midi_io`): ядру запрещено импортировать Commons, а кодек нейтрален
и про проект не знает. Отсюда `toSmf`, `writeMidi` (формат 1: дорожка-дирижёр
с темпом и размером + по дорожке на партию) и `writeMidiTracks` (по файлу на
инструмент). Позиции не пересчитываются — тики проекта и SMF совпадают;
клипы раскрываются ровно так, как их играет движок. CLI-команда —
`euterpia midi`.

## `compose`

- `score` — музыкальная модель (события, такты, мотивы) с приёмами развития
  (транспозиция, увеличение) и выводом в текстовую нотацию ядра;
- `builder` — низкоуровневая сборка **произвольного** проекта: ноды любых
  типов, связи любых видов, дорожки — из описателей типов (#300);
- `song` — высокоуровневая раскладка «партии + сумматор» → `ProjectFormat`;
- `midi` — MIDI-экспорт раскладки: один файл или по файлу на партию
  (обёртки над `midi_export`);
- `engine` — рендер прямо из кода: `render(arr, wav)` через `loadScene` +
  `renderToWav` (без `build.sh` и CLI) (#300).

Полное руководство и каталог инструментов — **[docs/libs/compose](../docs/libs/compose/README.md)**.

Почему на Nim, а не скриптом: проект — это данные Core (`core/project`), и
генерировать их лучше тем же типом, что и читает ядро. Это исключает
расхождение форматов, даёт проверки компилятора и не тянет внешних
зависимостей.

Примеры — `compositions/dark-fantasy/generate.nim` («Cathedral of Ash»,
medieval dark fantasy) и `compositions/neo-romantic/generate.nim`
(неоклассический ансамбль). Обе пьесы собираются библиотекой и, для сверки, тем
же составом только через CLI (см. `build_via_cli.sh` рядом) — результат
совпадает.
